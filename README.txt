HAIR STYLIST VALENTINA DI CATERINO

FILE INCLUSI
- index.html: sito e modulo di richiesta appuntamento via WhatsApp.
- netlify.toml: configurazione minima Netlify.

Il numero WhatsApp di Valentina è già inserito nel file index.html.

CARICAMENTO DA IPHONE
1. Scarica ed estrai questo ZIP nell'app File.
2. Apri il repository hair-stylist-valentina su GitHub.
3. Torna alla pagina principale, scheda Code.
4. Tocca Add file > Upload files.
5. Carica index.html e netlify.toml (se richiesto, sostituisci i file esistenti).
6. Messaggio commit: Aggiorna sito e WhatsApp prenotazioni.
7. Conferma Commit changes su main.

Se Netlify è collegato al repository con pubblicazione automatica, pubblicherà il sito dopo il commit.

NOTA: il modulo invia richieste a WhatsApp. Non salva ancora le prenotazioni in un pannello amministrativo. Per il pannello occorre collegare Supabase.
